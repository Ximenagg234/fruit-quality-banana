# Informe IEEE

Informe: `informe.tex` y `informe.pdf` (IEEE de conferencia, 7 páginas), `refs.bib` (formato IEEE) y `figuras/`.
Estructura obligatoria: ver `../docs/REQUISITOS_LINEAMIENTOS.md`.

## Qué hay aquí
| Archivo | Para qué |
|---|---|
| `informe.tex`, `informe.pdf` | el informe y su versión compilada |
| `figuras/` | figuras que usa el informe |
| `ESTRUCTURA_INFORME.md` | qué lleva cada sección, de dónde sale cada cifra y los mensajes que debe decir el informe |
| `tablas_informe.md` | las tablas con los **números finales**, generadas desde los CSV (`python report/generar_tablas.py`) |
| `refs.bib` | referencias verificadas (las marcadas `[VERIFICAR]` no se citan hasta comprobarlas) |

Para compilar: subir `informe.tex`, `refs.bib` y `figuras/` a Overleaf (o usar Tectonic desde esta carpeta).
